# 호국영웅전 게임 디자인 문서

## 1. 한 줄 요약

한국의 위인(영웅)과 문화유산(타워)으로 임진왜란의 다섯 전장을 지키는 타워 디펜스.
**둘이서 호흡을 맞추는 합격기**, **유산 배치 퍼즐(유산 공명)**, **미리 읽는 적의 전술 카드**가 핵심입니다.

## 2. 핵심 루프

```
전투 전  : 영웅 고르기(혼자 2명 / 협동 각 1명) → 비기 2개 장착 → 전장·난이도 선택
전투 중  : 유산 건설 → 파도 대비(전술 카드 읽기) → 영웅 이동·기술 → 공명 모이면 합격기 → 강화·특화
전투 후  : 엽전·옥·공적 → 품계 승진(비기 해금) → 영웅·비기·유산 영구 강화 → 임무 보상 → 다음 전장
매일/매주 : 출석부, 일일 임무 3개, 주간 임무 4개 (모두 깨면 보너스)
```

## 3. 전투 시스템

### 3.1 자원과 목숨
- **군자금(냥)**: 전투 안에서만 쓰는 돈. 처치 보상, 파도 시작 보급(20+4×파도), 조기 호출 보너스(남은 초×2), 경복궁 수입.
- **민심**: 목숨. 보통 20 / 어려움 15 / 지옥 10. 적이 도성에 닿으면 적의 `lives` 값만큼 줄어듭니다(졸병 1 · 정예 2 · 중장 3~5 · 적장 6~10, 최종 적장은 즉시 패배).
- **별**: 민심 90% 이상 ★★★, 50% 이상 ★★, 그 외 ★.

### 3.2 피해 유형
| 유형 | 막는 능력치 | 비고 |
|---|---|---|
| 물리 | 갑옷 | 궁수·영웅 근접. 철갑무사(갑옷 60%)에 약함 |
| 화기 | 갑옷의 절반 | 수원화성·비기 폭발 |
| 신성 | 저항 | 첨성대·보신각·석굴암·해인사. 음양사(저항 50%)에 약함 |

해인사는 범위 안 적의 갑옷(과 특화 시 저항)을 깎아 다른 유산을 돕습니다. 관상감·인정파루·봉수 경보는 "받는 피해 증가"를 겁니다.

### 3.3 유산 (타워)
| 유산 | 계열 | 역할 | 甲 특화 | 乙 특화 |
|---|---|---|---|---|
| 숭례문 | 궁궐 | 값싼 단일 궁수 | 편전 명궁: 장거리·치명타·강적 우선 | 연사 궁대: 3연발 |
| 수원화성 | 성곽과학 | 범위 화포 | 홍이포: 큰 폭발 + 기절 | 화차 신기전: 6발 흩뿌리기 |
| 보신각 | 궁궐 | 주변 전체 종소리 + 둔화 | 에밀레종: 3타마다 기절 | 인정·파루: 강한 둔화 + 취약 |
| 첨성대 | 성곽과학 | 장거리 신성 · **은신 탐지** | 혼천의: 3타마다 유성 | 관상감: 취약 +25% · 탐지 확대 |
| 해인사 | 사찰 | 오라: 갑옷 약화 · 둔화 · 지속 피해 | 경판 결계: 갑옷·저항 크게 약화 | 호국 법회: 처치 +3냥 · 영웅 치유 |
| 석굴암 | 사찰 | 오래 비출수록 강해지는 광선 | 대광명: 최대 7배 (적장 사냥) | 천불 광배: 2명에게 갈라짐 |
| 경복궁 | 궁궐 | 주변 유산 강화 + 파도마다 수입 | 왕도 정치: 강화 +45% · 사거리 | 호조 국고: 수입 90 + 이자 |

- 모든 유산은 1→2→3단계 강화 후 甲/乙 중 하나로 **특화**합니다(되돌릴 수 없음).
- 조준 우선순위: 선두 / 후미 / 강적 / 근접.
- 철거 시 투자액의 70% 환급. 협동에서는 **돈을 낸 사람에게 낸 만큼** 돌려줍니다. 동료 유산도 내 돈으로 강화할 수 있지만 철거는 주인만.
- 해금: 숭례문·수원화성·보신각·첨성대는 처음부터, 해인사(부산진 승리), 석굴암(탄금대 승리), 경복궁(한산도 승리).

### 3.4 유산 공명 (킥 ②)
같은 계열의 **다른 종류** 유산이 체비셰프 거리 2칸 안에 있으면 1종당 공격력 +12%.
- 궁궐: 숭례문 · 보신각 · 경복궁 (최대 +24%)
- 사찰: 해인사 · 석굴암 (+12%)
- 성곽과학: 수원화성 · 첨성대 (+12%)
- 경복궁은 공명 1종당 강화 오라 효과 ×1.25.

같은 유산만 늘어놓는 것보다 섞어 짓게 만드는 장치입니다. 건설 미리보기에서 공명선과 "+24%"가 바로 보여서, 초보도 배치 퍼즐을 체감합니다.

### 3.5 영웅
| 영웅 | 역할 | 상시 | 기술 (Q) | 궁극기 (W) |
|---|---|---|---|---|
| 이순신 | 원거리 · 지휘 | 필사즉생: 주변 유산 공속 +12% | 학익진: 부채꼴 화살 | 거북선 출격: 길을 거슬러 돌진·밀어내기 |
| 세종대왕 | 지원 · 통제 | 집현전: 처치 군자금 +10% | 훈민정음: 한글 자모 비 + 기절 | 자격루: 전장 50% 둔화 + 유산 재장전 |
| 을지문덕 | 범위 · 전략 | 여수장우중문시: 주변 적 갑옷 -20% | 청야전술: 불 장판 | 살수대첩: 큰 피해 + 3칸 뒤로 쓸어냄 |
| 강감찬 | 근접 · 적장 사냥 | 낙성: 4타마다 별똥별 | 귀주 돌격: 돌진 + 기절 | 낙성우: 가장 강한 적 8명에 유성 |
| 권율 | 근접 · 방어 | 행주치마: 초당 1.5% 회복, 3명 저지 | 투석: 돌 6개 + 기절 | 행주산성: 목책으로 길 봉쇄 6초 |
| 곽재우 | 기동 · 게릴라 | 천강홍의: 주변 은신 탐지 | 의병 매복: 의병 3명 소환 | 홍의 질풍: 8초 무적 + 공속 2배 + 튕기는 화살 |

- 근접 영웅(강감찬·권율)과 의병은 적을 **저지(블록)** 합니다. 기마무사·시노비는 저지되지 않습니다.
- 전투 중 처치 경험치로 레벨 1→10 (체력 +9%, 공격 +8%/레벨). 쓰러지면 (12+레벨)초 뒤 도성에서 부활.
- 해금: 이순신·세종은 처음부터, 나머지는 전장 승리 + 엽전.

### 3.6 비기 (장착 스킬)
품계가 오르면 해금되고, 전투마다 2개를 장착합니다. 영구 강화 1단계당 효과 +10%, 재사용 -3%.

신기전 일제사격(범위 로켓 12발) · 봉수 경보(은신 발각 + 받는 피해 +20%) · 의병 소집(길목 저지) · 비격진천뢰(2초 뒤 폭발 + 기절) ·
군량 보급(즉시 군자금, 동료도 절반) · 천자총통(가장 강한 적에게 900) · 동의보감(영웅 전원 회복·부활) · 동장군 한파(얼음 장판).

### 3.7 합격기 (킥 ①)
- **공명 게이지(태극)**: 적 처치(영웅 처치는 3배), 기술·비기 사용, 전투 시간으로 차오릅니다. 보통 한 전장에서 3~10회.
- **발동 조건**: 게이지 100 + 두 영웅 생존 + 두 영웅 거리 5칸 이내.
- **호흡 맞추기**: 협동에서는 한 사람이 누르면 2.5초 창이 열리고, 다른 사람이 그 안에 눌러야 발동합니다. 혼자서는 한 번에 발동.
- **연출**: 두 영웅 초상과 붓글씨 이름이 화면을 가로지르고, 화면이 흔들리며 징과 북이 울립니다.

| 조합 | 합격기 | 효과 |
|---|---|---|
| 이순신 + 세종대왕 | 성군과 성웅 | 10초 유산 공격 +60%·공속 +20%, 모든 길에 거북선 |
| 을지문덕 + 강감찬 | 살수낙성 | 모든 적 신성 350 + 4초 50% 둔화 |
| 권율 + 곽재우 | 의병 궐기 | 모든 길목 정예 의병, 영웅 무적·공격 2배, 적 둔화 |
| 이순신 + 권율 | 수륙병진 | 모든 적 화기 400 + 기절 1.5초 |
| 세종대왕 + 을지문덕 | 문무겸전 | 10초 모든 적 갑옷·저항 0, 모두 군자금 +150 |
| 이순신 + 강감찬 | 불멸의 대첩 | 가장 강한 적 12명에 신성 500 |
| 그 밖의 조합 | 호국 합격 | 모든 적 피해 + 기절(영웅 주변 1.5배), 모두 +60냥 |

영웅 조합을 고르는 것 자체가 전략이 되도록, 출전 준비 화면에서 합격기를 미리 보여 줍니다.

### 3.8 왜군 전술 카드 (킥 ③)
3파도부터(적장 파도 제외) 45% 확률로 다음 파도의 전술이 공개됩니다.

| 전술 | 효과 | 대비 | 파훼 보너스 |
|---|---|---|---|
| 조총 일제사격 | 조총병 8명 추가, 조총 피해 ×1.5 | 영웅을 사거리 밖으로 | +40 |
| 야습 | 유산 사거리 -15%, 시노비 4명 | 첨성대·봉수 경보 | +60 |
| 강행군 | 이동 +25%, 체력 -10% | 보신각·해인사 둔화 | +40 |
| 철갑 행렬 | 갑옷 +15%p | 해인사, 신성·화기 | +50 |
| 기마 돌격 | 기마무사 6명 뒤따라 돌격 | 둔화·범위 피해 | +50 |
| 음양 결계 | 음양사 3명, 저항 +20%p | 물리·화기 비중 | +50 |

"미리 알려 주고, 대비하면 보상"하는 구조라서 다음 파도 카드가 매번 작은 퍼즐이 됩니다.

### 3.9 왜군
| 등급 | 종류 | 특징 |
|---|---|---|
| 졸병 | 아시가루 · 조총병 · 척후병 | 수로 밀기 · 영웅 저격 · 빠름 |
| 정예 | 사무라이 · 시노비 · 음양사 · 기마무사 · 진군 고수 | 체력 절반에 돌진 · 은신 · 치유(겹치지 않음) · 저지 불가 · 주변 가속 |
| 중장 | 철갑무사 · 공성 충차 | 갑옷 60% · 파괴 시 아시가루 4명 |
| 적장 | 고니시 · 가토 · 와키자카 · 우키타 · 태합의 망령 | 병력 소환 · 유산 봉쇄 돌격 · 보호막 · 전군 독려 · 단계별 저주 |

## 4. 협동 디자인

| 방식 | 조작 | 특징 |
|---|---|---|
| 혼자 | 마우스 + 키 | 두 영웅을 모두 지휘 (Tab/1/2로 선택) |
| 로컬 2인 | 1P 마우스만 / 2P 키보드만 (방향키 + 왼손 A S D F · E · Space) | 2P는 영웅을 직접 몰고 **발밑에 건설**. 입력 장치를 완전히 나눠 둘이 겹치지 않게 설계 |
| 온라인 2인 | 각자 마우스 | 방 코드 4자리, 호스트 권한, 초당 15회 스냅샷 |

- **돈은 각자**: 처치 보상은 두 사람 모두 60%씩(합 120%), 시작 자금 65%씩. 적 체력은 협동에서 +20%.
- **각자의 길**: 행주대첩·한양처럼 두 갈래 길이 있는 전장은 "한 사람이 한 길씩"이 자연스럽게 나옵니다.
- **서로 돕기**: 동료 유산을 내 돈으로 강화할 수 있고, 군량 보급은 동료에게도 절반을 줍니다. 합격기는 둘이 같이 눌러야 합니다.
- **소통**: G 키 핑, 합격기 대기 알림("동료가 합격기를 눌렀습니다! Space로 호흡을 맞추세요").
- **끊김 처리**: 참가자가 나가면 호스트가 영웅·유산·군자금을 넘겨받아 계속 싸웁니다.

## 5. 메타 성장과 보상

| 보상 | 획득처 | 쓰는 곳 |
|---|---|---|
| 엽전 | 전투(파도·승리·별), 임무, 출석, 승진 | 영웅 해금·강화, 비기 강화, 유산 복원 |
| 옥 | 첫 승리(30), ★★★ 승리, 임무, 출석, 승진 | (예비 재화: 향후 치장·영웅 조기 해금) |
| 공적 | 전투 | 품계 승진 → 비기 해금 + 보상 |

- 품계 18단계: 종9품 권관 → 정1품 영의정.
- 일일 임무(자정 초기화) 풀 13종 중 3개, 주간 임무(월요일 초기화) 풀 8종 중 4개. 날짜 시드로 뽑아 누구나 같은 날 같은 임무를 받습니다.
- 출석부 7일 순환(7일째 옥 50 + 엽전 500).

## 6. 시각·청각 디자인

- **팔레트**: 옻칠 검정(#1c1511) 바탕, 오방색 단청 띠(녹청·주홍·황·청·백)를 모든 패널 윗면에 둘러 한국적 인상을 한 곳에 모읍니다. 한지(#efe4cc)는 도움말 카드와 타이틀에만 씁니다.
- **글꼴**: 제목·연출은 나눔손글씨 붓, 숫자·버튼은 검은고딕(Black Han Sans), 본문은 고운바탕.
- **그래픽**: 이미지 파일 없이 전부 캔버스 코드로 그립니다. 기와지붕(처마 들림), 단청, 홍예문, 석축, 첨성대의 병 모양, 석굴암 돔, 근정전의 2단 월대.
- **전장 계절**: 부산진(봄, 벚꽃) · 탄금대(여름, 반딧불이) · 한산도(바다) · 행주산성(겨울, 눈) · 한양(가을, 단풍).
- **소리**: WebAudio로 합성. 가야금 뜯는 소리, 장구의 굿거리풍 장단, 징, 범종, 나발. 적장 파도에서는 빠른 장단으로 바뀝니다.

## 7. 기술 구조

- 시뮬레이션은 **순수 JSON 상태 + 시드 난수 + 명령 큐**. 같은 시드·같은 명령이면 같은 결과(자체 점검으로 확인).
- 렌더러는 상태만 읽습니다. 그래서 온라인 참가자는 스냅샷을 받아 같은 렌더러로 그리고, 위치는 스냅샷 사이를 보간합니다.
- 서버는 Node 표준 라이브러리만으로 WebSocket 핸드셰이크·프레임을 직접 처리하는 방 중계기입니다(설치 없음).
