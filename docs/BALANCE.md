# 밸런스 노트

모든 수치는 `src/data/`에 모여 있고, 바꿀 때마다 봇 시뮬레이션으로 확인합니다.
감으로 맞추지 않고 **"평범한 플레이어라면 어떻게 될까"를 봇으로 수백 판 돌려 본 결과**로 조정했습니다.

## 1. 측정 도구

| 도구 | 무엇을 재나 |
|---|---|
| `tools/balance.mjs` | 봇이 전장 5 × 난이도 3 × (혼자/협동)을 시드별로 자동 플레이. 승률, 남은 민심, 도달 파도, 합격기 횟수 |
| `tools/towerlab.mjs` | 유산 하나를 길 옆에 두고 적 행렬을 60초 흘려 **군자금 100냥당 DPS** 측정 (졸병 떼 / 철갑 / 적장) |
| `tools/heromatrix.mjs` | 영웅 2인 조합 15가지를 같은 조건으로 플레이해 조합 간 격차 확인 |
| `tools/selftest.mjs` | 같은 시드 → 같은 결과(결정성), 스냅샷 왕복, 명령 검증 |

### 봇은 어떤 플레이어인가
- 경로를 많이 덮는 빈 터부터 **정해진 순서**(숭례문 → 숭례문 → 수원화성 → 보신각 → 강화 → 첨성대 …)로 건설·강화합니다.
- 다음 파도 미리보기를 읽고 **시노비가 오면 길마다 첨성대**, **철갑·충차가 오면 석굴암·첨성대**를 먼저 짓습니다.
- 기술은 적이 3명 이상 몰린 곳에, 궁극기·지정 비기는 적장이 있으면 적장에게 씁니다. 파도를 일찍 부르지 않고, 영웅을 잘 옮기지도 않습니다.
- 즉 **배치·조기 호출·영웅 운용은 사람보다 서툴고, 돈 쓰는 속도는 사람보다 빠른** 플레이어입니다.

## 2. 목표

| 난이도 | 목표 |
|---|---|
| 보통 | 봇이 전 전장 승리. 부산진은 튜토리얼이라 ★★★ 쉽게, 후반으로 갈수록 ★★ 쪽으로 |
| 어려움 | 앞 3개 전장은 봇도 가능, 행주·한양은 **영구 강화 + 좋은 플레이**가 필요 |
| 지옥 | 봇은 대부분 실패. 영구 강화를 끝까지 올려야 앞 전장이 겨우 가능 |
| 협동 | 혼자와 비슷한 난도 (적 체력 +20%, 보상은 두 사람 합 120%) |
| 전략 | 한 가지 유산만 짓거나 기술을 안 쓰면 후반에 반드시 막혀야 함 |

## 4. 유산 효율 (군자금 100냥당 DPS)

`node tools/towerlab.mjs <적> <간격>` — 적을 죽지 않게 해 순수 출력만 잰 값이라 절대값보다 **비교**에 의미가 있습니다.

| 유산 | 1단계 (졸병 떼) | 甲 (졸병 / 철갑 / 적장) | 乙 (졸병 / 철갑 / 적장) |
|---|---|---|---|
| 숭례문 | 18.6 | 편전 명궁 22.9 / 8.2 / 6.5 | 연사 궁대 25.6 / 9.3 / 1.8 |
| 수원화성 | 20.4 | 홍이포 32.7 / 11.0 / 5.4 | 화차 신기전 23.1 / 12.6 / 5.3 |
| 보신각 | 20.6 | 에밀레종 38.8 / 16.3 / 1.3 | 인정·파루 38.3 / 15.6 / 1.0 |
| 첨성대 | 18.3 | 혼천의 32.7 / 19.5 / 13.7 | 관상감 18.6 / 16.3 / 11.3 (+ 취약 25%) |
| 석굴암 | 20.0 | 대광명 22.4 / 36.5 / **17.4** | 천불 광배 29.5 / 36.8 / 6.7 |
| 해인사 (숭례문 옆) | 20.8 | 경판 결계 31.7 / 17.3 | — |

읽는 법:
- **졸병 떼**에는 보신각·수원화성, **철갑**에는 석굴암·첨성대, **적장**에는 석굴암 대광명·혼천의가 강합니다.
- 숭례문은 싸고 무난하지만 철갑과 적장에는 약합니다. "숭례문만 짓기"가 후반에 막히는 이유입니다.
- 보신각은 떼에게 가장 효율이 좋지만 적장에게는 거의 무력해서, 적장 파도 대비는 따로 해야 합니다.
- 경복궁은 혼자서는 약해 보이지만(옆 유산 하나 기준 6.8) 주변 6~8개 유산을 동시에 올리고 매 파도 수입이 있습니다.

## 5. 주요 조정 기록

| 문제 (측정으로 발견) | 조정 |
|---|---|
| 보신각이 졸병 떼 상대로 다른 유산의 2배 효율 (36 → 80) | 피해 16/26/38 → 9/14/20, 특화도 약 절반으로 |
| 해인사 오라 피해가 범위 내 모든 적에게 들어가 과도 | 초당 피해 절반, 갑옷 약화를 핵심 역할로 |
| 적장이 새면 민심이 한 번에 10~15 빠져 결과가 복불복 | 적장 체력을 파도 성장에서 분리(스테이지 배율만), 적장 민심 피해 6~10으로 |
| 와키자카 보호막이 14초마다 25% → 사실상 체력 3배 | 15초마다 12%로 |
| 음양사 여럿이 서로 치유해 불사신이 됨 | **치유는 겹치지 않음**(한 적은 2.5초에 한 번만) |
| 이순신+세종만 이기고 나머지 조합은 한양에서 패배 | 기본 합격기를 전장 전체 피해로, 권율·곽재우 강화, 의병 궐기에 둔화 추가 |
| 한양 초반 기마·시노비 파도에서 붕괴 | 4·5·8파 구성 완화, 시작 군자금 450 |
| 두 갈래 전장(행주·한양)에서 방어선을 둘 세울 돈 부족 | 시작 군자금 390 / 450 |
| 대광명이 적장 상대로 혼천의보다 약함 (역할 뒤바뀜) | 대광명 초당 72 → 85, 최대 6배 → 7배, 충전 3.5초 → 3초. 혼천의 150 → 135 |
| 지옥에서 영구 강화를 다 해도 두 번째 전장부터 불가능 | 적 체력 ×1.8 → ×1.6, 처치 보상 ×0.85 → ×0.9 |

## 6. 손볼 때 참고

- 전장 난도는 `stages.js`의 `hpBase`(시작 배율), `hpGrowth`(파도당 +10%), `startGold`로 조절합니다.
- 파도 문법은 `"ash*10@0.8+3>1"` = 아시가루 10명, 0.8초 간격, 3초 지연, 1번 길.
- 협동 보정은 `COOP = { hpMult: 1.2, goldShare: 0.6, startGoldShare: 0.65 }`.
- 수치를 바꾼 뒤에는 `npm run balance`와 `npm test`를 함께 돌려 보세요.
