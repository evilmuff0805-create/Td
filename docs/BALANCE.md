# 밸런스 노트

모든 수치는 `src/data/`에 모여 있고, 바꿀 때마다 봇 시뮬레이션으로 확인합니다.
감으로 맞추지 않고 **"평범한 플레이어라면 어떻게 될까"를 봇으로 수백 판 돌려 본 결과**로 조정했습니다.

## 1. 측정 도구

| 도구 | 무엇을 재나 |
|---|---|
| `tools/balance.mjs` | 봇이 전장 5 × 난이도 3 × (혼자/협동)을 시드별로 자동 플레이. 승률, 남은 민심, 도달 파도, 합격기 횟수 |
| `tools/towerlab.mjs` | 유산 하나를 길 옆에 두고 적 행렬을 60초 흘려 **군자금 100냥당 DPS** 측정 (졸병 떼 / 철갑 / 적장) |
| `tools/heromatrix.mjs` | 영웅 2인 조합 15가지를 같은 조건으로 플레이해 조합 간 격차 확인 |
| `tools/selftest.mjs` | 같은 시드 → 같은 결과(결정성), 스냅샷 왕복, 명령 검증 |

### 봇은 어떤 플레이어인가
- 경로를 많이 덮는 빈 터부터 **정해진 순서**(숭례문 → 숭례문 → 수원화성 → 보신각 → 강화 → 첨성대 …)로 건설·강화합니다.
- 다음 파도 미리보기를 읽고 **시노비가 오면 길마다 첨성대**, **철갑·충차가 오면 석굴암·첨성대**를 먼저 짓습니다.
- 기술은 적이 3명 이상 몰린 곳에, 궁극기·지정 비기는 적장이 있으면 적장에게 씁니다. 파도를 일찍 부르지 않고, 영웅을 잘 옮기지도 않습니다.
- 즉 **배치·조기 호출·영웅 운용은 사람보다 서툴고, 돈 쓰는 속도는 사람보다 빠른** 플레이어입니다.

## 2. 목표

|---|---|
| 보통 | 봇이 전 전장 승리. 부산진은 튜토리얼이라 ★★★ 쉽게, 후반으로 갈수록 ★★ 쪽으로 |
| 어려움 | 앞 3개 전장은 봇도 가능, 행주·한양은 **영구 강화 + 좋은 플레이**가 필요 |

## 4. 유산 효율 (군자금 100냥당 DPS)

`node tools/towerlab.mjs <적> <간격>` — 적을 죽지 않게 해 순수 출력만 잰 값이라 절대값보다 **비교**에 의미가 있습니다.

| 유산 | 1단계 (졸병 떼) | 갑 특화 (졸병 / 철갑 / 적장) | 을 특화 (졸병 / 철갑 / 적장) |
|---|---|---|---|
| 숭례문 | 18.6 | 편전 명궁 22.9 / 8.2 / 6.5 | 연사 궁대 25.6 / 9.3 / 1.8 |
| 수원화성 | 20.4 | 홍이포 32.7 / 11.0 / 5.4 | 화차 신기전 23.1 / 12.6 / 5.3 |
| 보신각 | 20.6 | 에밀레종 38.8 / 16.3 / 1.3 | 인정·파루 38.3 / 15.6 / 1.0 |
| 첨성대 | 18.3 | 혼천의 32.7 / 19.5 / 13.7 | 관상감 18.6 / 16.3 / 11.3 (+ 취약 25%) |
| 석굴암 | 20.0 | 대광명 22.4 / 36.5 / **17.4** | 천불 광배 29.5 / 36.8 / 6.7 |
| 해인사 (숭례문 옆) | 20.8 | 경판 결계 31.7 / 17.3 | — |

읽는 법:
- **졸병 떼**에는 보신각·수원화성, **철갑**에는 석굴암·첨성대, **적장**에는 석굴암 대광명·혼천의가 강합니다.
- 숭례문은 싸고 무난하지만 철갑과 적장에는 약합니다. "숭례문만 짓기"가 후반에 막히는 이유입니다.
- 보신각은 떼에게 가장 효율이 좋지만 적장에게는 거의 무력해서, 적장 파도 대비는 따로 해야 합니다.
- 경복궁은 혼자서는 약해 보이지만(옆 유산 하나 기준 6.8) 주변 6~8개 유산을 동시에 올리고 매 파도 수입이 있습니다.

## 5. 주요 조정 기록

| 문제 (측정으로 발견) | 조정 |

## 6. 25개 전장으로 늘린 뒤 (2차 조정)

전장이 5곳에서 25곳으로 늘면서, 각 전장을 **그 시점의 예상 영구 강화 수준**에 맞춰 봇으로 다시 맞췄습니다.

| 몇 번째 전장 | 영웅 강화 | 비기 강화 | 유산 복원 |
|---|---|---|---|
| i번째 (0부터) | min(10, 0.45·i) | min(5, 0.22·i) | min(30, 1.3·i) |

- **`tools/tune.mjs`**: 전장마다 일반 병력의 체력 배율 `hpBase`를 이분 탐색합니다. 목표는 "봇이 4판 중 3판 이상 이기고, 남은 민심이 앞 전장 85% → 마지막 전장 60%"가 되는 가장 높은 배율입니다. 부산진(튜토리얼)만 1.0으로 고정.
- **적장 체력은 따로**: 적장이 `hpBase`를 따라가면 적장이 센 전장의 일반 병력이 지나치게 약해져서, 적장은 전장 순서대로 고르게 오르는 배율(0.9 + 0.045 × 순서)을 씁니다.
- **중간 적장**: 마지막 파도가 아닌 적장은 등장 시점에 따라 35~95% 체력. 방어선이 덜 갖춰진 이른 파도의 적장이 민심 8을 한 번에 빼앗는 일을 막습니다.
- **보호막 수군 장수**: 도도(보호막+상륙)·구키(두꺼운 보호막)가 측정에서 가장 자주 샜습니다 → 체력·보호막 비율을 낮췄습니다.
- **도요토미 히데요시**: 전장 배율과 상관없는 고정 체력 38,000 · 갑옷 88% · 저항 55%. 영구 강화를 끝까지 올린 봇이 **아슬아슬하게** 이기는 수준(4판 중 3판 승, 진 판도 5% 이하까지 몰아붙임)입니다. 물리 위주 조합은 막히고, 화기(수원화성·안중근·신기전·비격진천뢰)와 신성(석굴암·첨성대·단군), 갑옷 깎기(해인사·을지문덕·문무겸전)를 섞어야 합니다.

**새 영웅 두 명**: 모든 2인 조합(28개)을 진주대첩 어려움으로 돌린 영웅별 평균 점수에서 처음 안중근 8.9 · 단군 8.7로 다른 영웅(4~7)보다 확실히 강했습니다.
안중근 공격 46 → 32 · 적장 추가 피해 30% → 25% · 기술·궁극기 소폭 하향, 단군 공격 20 → 17 · 회복 오라 1% → 0.7% · 기술·궁극기 소폭 하향 후 안중근 5.5 · 단군 4.3으로 무리 안에 들어왔습니다(권율 3.4 ~ 강감찬 6.6).

- **협동**: 적 체력 보정을 +20% → **+10%**로 낮췄습니다. 둘이 따로 군자금을 쓰다 보니 후반 전장에서 혼자보다 약간 불리했기 때문입니다. 2판 기준 모든 전장 1판 이상 승리(4판으로 다시 돌린 전장은 모두 3판 이상).
- **어려움**: 중반 이후는 봇이 거의 막힙니다. 예상치 이상의 영구 강화와 사람의 판단(기술 타이밍·유산 배치)이 필요한 벽으로 의도한 것입니다.

## 7. 새 유산 3종 (남한산성 · 석빙고 · 불국사)

전장 난도는 기존 `balanced` 봇 전략에 맞춰져 있으므로 **그대로 두고**, 새 유산은 "기존 유산 자리를 대신 채웠을 때 비슷하게 싸우는가"로 맞췄습니다.
`tools/balance.mjs --plan=nam|ice|bul`: balanced 전략에서 숭례문 둘 → 남한산성, 보신각 둘 → 석빙고, 석굴암 둘 → 불국사로 바꾼 전략입니다. (봇은 남한산성을 길에 가장 가까운 칸에 짓습니다.)

12개 전장 × 4판, 보통 · 혼자, 예상 영구 강화:

| 전략 | 1차 수치 | 조정 후 |
|---|---|---|
| balanced (기준) | 46/48승 · 평균 민심 16.2 | — |
| 남한산성 | 42/48 · 13.4 | 45/48 · 13.9 → 1·2단계 값 인하 후 가장 약하던 6곳 평균 민심 11.7 → 12.8 |
| 석빙고 | 38/48 · 13.3 | 45/48 · 15.0 |
| 불국사 | 34/48 · 10.6 | 43/48 · 14.8 |

- **불국사**: 유산 실험실(`towerlab.mjs`, 적 체력 ×30)에서는 철갑무사 상대로 100냥당 피해가 다른 유산의 두 배로 나와 한 번 크게 깎았지만, 실제 전장에서는 오히려 약했습니다(1차 34/48). 실험실은 체력을 부풀려 상한에 늘 닿기 때문입니다. 실제 적 체력에서는 상한에 덜 닿으므로 처음 수치 가까이 되돌리고 상한만 조금 낮췄습니다. 히데요시(체력 38,000) 상대로 석가탑은 대광명과 비슷한 초당 피해를 냅니다 — 갑옷 88%를 무시하는 대신 한 번에 650까지만.
- **석빙고**: 처음엔 한 적만 맞혀 졸병 떼에 약했습니다 → 맞은 자리 둘레(0.5~0.6칸)도 느려지게 하고 피해를 올렸습니다. 얼리기는 맞은 적 하나만(한파 특화는 둘레 전부), 적장은 기절 규칙대로 35%만.
- **남한산성**: 병사 체력 · 피해를 15% 올리고 1 · 2단계 값을 100 → 90, 80 → 75냥으로. 적장은 병사를 두 배로 베므로 적장을 오래 붙잡지는 못합니다. 봇은 병사를 길목 한가운데 세우지 못해서 실제 사람보다 덜 활용합니다.
- 전장 난도(`HP_BASE`)는 바꾸지 않았고, 기준 전략 결과도 그대로입니다(위 25개 전장 표와 같은 값).

## 8. 손볼 때 참고

- 전장 난도는 `stages.js`의 `HP_BASE`(일반 병력 배율 — `node tools/tune.mjs`로 다시 맞출 수 있음), `hpGrowth`(파도당 +10%), `startGold`로 조절합니다. 새 전장의 파도는 `gen`(level · 가중치 · 적장)으로 생성합니다.

- 수치를 바꾼 뒤에는 `npm run balance`와 `npm test`를 함께 돌려 보세요.
