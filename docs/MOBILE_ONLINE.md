# 모바일 패드와 1인 1영웅 전환

2026-10-18 · 아스트라 최종 승인, 공개 배포·검수 완료

후속 페이지 확대 방지·웨이브 설명 제거·옥→엽전 교환과 최신525개 검사는 [모바일 사용성 수정](MOBILE_UX.md)을 따른다. 아래는1영웅/방 협동 전환 당시 기록이다.

사용자가 솔로도 영웅 한 명만 출전하고, 로컬 2인을 없애며 방 만들기·참가에 협동을 모으도록 요청했다. 아스트라를 본부장 승인자로 지정했고, 계획·리스크 검토 뒤 구현 착수와 제한된 솔로 피해 보정을 승인받았다. [계획](MOBILE_ONLINE_TRANSITION_PLAN.md) · [승인·리스크 기록](MOBILE_ONLINE_RISK_REVIEW.json)

## 플레이 규칙과 조작

- 솔로는 플레이어1명·영웅1명·장착 비기2개다.
- 온라인은 방 만들기 → 코드 참가 → 각자 서로 다른 영웅1명 → 참가자 준비 → 방장 출전이다. 각자 자기 영웅·군자금·보급품을 사용한다.
- 휴대폰은 왼쪽 아래 가상 패드로 이동하고 빈 터를 터치해 건설한다. 오른쪽 기술 버튼 후 전장을 터치해 시전한다. 이동·건설 모드 버튼은 없다.
- PC는 빈 터 클릭으로 건설, 우클릭/길 클릭으로 내 영웅 이동, Q/W 기술·궁극기, D/F 장착 비기, Z/X/C/V 보급품이다.
- 로컬2인 준비 화면·진입·방향키/ASDF/E 전용 조작·2P 커서·지휘 인계를 제거했다.
- 합격기와 협동 임무는 온라인 전용이다. 해당 임무가 포함된 전체완료 보너스에는 온라인 플레이가 필요할 수 있다고 표시한다. 기존 임무 진행·보상을 보존한다.

가상 패드는 화면 방향을 전장 방향으로 바꾸고, 게스트의 늦은 표시 좌표 대신 이동 방향을 보낸다. 호스트가 자신의 현재 좌표에서 짧은 목적지를 계산한다. 정지도 호스트 현재 좌표에서 처리한다. 패드와 전장 터치 포인터를 분리해 이동 중 다른 손가락으로 건설·기술을 사용할 수 있다. 전장 자체의 두 손가락 제스처·드래그는 건설로 오인하지 않는다.

## 연결·종료·저장

일시적인 연결 끊김은 기존 최대30초 복구 유예와 상태·그림 준비 ACK를 사용한다. 호스트가 백그라운드로 가면 진행·입력을 기다리며, 복귀 시 현재 백그라운드 상태를 포함한 전체 스냅샷으로 다시 맞춘다. 재연결 전에 누르던 패드 명령을 재생하지 않는다. 새로고침·OS 종료 복원과 호스트 교체는 지원 범위에 포함하지 않는다.

영구 이탈이 먼저 확정되면 서버가 시작된 방을 닫아 늦은 승리 패킷을 거부한다. 영웅·유산·군자금을 인계하지 않고, 보상·패배·전투완료 통계 없이 방 화면으로 돌아간다. 서버가 정상 종료를 먼저 확정했으면 결과를 한 번 처리한다. 종료·중단은 열려 있던 메뉴와 퇴장 확인 창도 취소한다.

기존 솔로 편성은 첫 유효하고 해금된 영웅 한 명으로 읽는다. 엽전·옥·영구 강화·해금·의상·보급품·전장 성적·협동 통계를 초기화하지 않는다. 과거 `loadout.p2`는 호환 데이터로 읽어 두되 출전에 사용하지 않는다. 저장소 키와 주소별 브라우저 저장 방식은 유지한다.

## 보통 솔로 피해 보정

**보통 난이도 + 솔로 + 플레이어1명 + 영웅1명**일 때 영웅 출처의 실제 피해에 **1.5배**를 한 번 적용한다. 기본 공격·직접 기술·거북선·영웅 출처 지속 피해를 포함한다. 소환 병사의 피해·HP, 회복량·기절 시간·영웅 HP·시작 군자금은 변경하지 않았다. 온라인·기존2영웅 순수 시뮬레이션·어려움·지옥에는 이 보정을 적용하지 않는다.

첫 무보정 성장 실행은16/25에서 멈췄다. 고정된 s17 진입 레벨과 시드에서는 보정별 성적이 비단조적이어서 해당 표본만으로 수치를 선택하지 않았다. 신규 프로필 전체 성장 비교에서1.25배는 두 시드 중 하나만25전장 완료했고,1.5배는 두 시드 모두 완료했다. 아스트라 승인 후 최종 소스 식별값·배율을 포함해 세 시드로 다시 검증했다.

| 최종 실행 | 완료 | 전투 수 | 패배/재도전 |
|---|---:|---:|---:|
| 이순신·seed1 | 25/25 | 33 | 8 |
| 이순신·seed2 | 25/25 | 31 | 6 |
| 이순신·seed3 | 25/25 | 34 | 9 |

같은 날 신규 프로필, 출석1회, 실제 획득 전투·품계·임무 보상과 비용을 지불한 강화만 사용했다. 무료 강화·옥 환전·허위 해금을 넣지 않았다. 이순신의 자동 전략 결과이며 모든 영웅의 캠페인 완주나 사람의 적정 난이도를 보증하지 않는다. 곽재우는 별도의 무강화 대표 전장 검사에서 s1 승리, s17 패배를 기록했고 소환 동작의 유효 상태를 확인했다. 후반 전체 밸런스 조정은 계속 보류한다.

## 검증과 실제 화면

## 패키지와 공개 범위

웹은 정식 `index.html`과 `assets/3d/app.js`로만 진입한다. 공개 패키지에서 자유 미리보기 `3d.html`·`game.js`·관련 CSS와 타이틀 링크를 제외하고, 공개 허용 목록에서도 해당 HTML/JS를 차단했다. 기존 manifest 소유 파일 정리와 실제 파일이 남아 있는 소스 루트 양쪽에서 GET/HEAD 차단을 검사한다. **로컬 개발용 자유 미리보기는2영웅 아트 검수 도구**로 보존하며 정식 조작·성장 검증과 구분한다.

웹 그림195개는 원본과 바이트가 같고, Windows 웹 파일211개 합계127,306,084바이트다. ZIP은126,246,005바이트이며 manifest 전체 SHA와 대조했다. 단일 HTML은168,637,794바이트이며 솔로만 가능하다. Linux 공개 빌드의 합계는 줄바꿈 차이로127,303,262바이트이며 공개 `app.js`1,445,963바이트는 Windows 승인 빌드와 정확히 같다.
