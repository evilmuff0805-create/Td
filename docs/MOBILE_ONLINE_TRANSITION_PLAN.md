# 모바일 영웅 조작과 온라인 협동 전환 계획

2026-10-18 · **계획과 리스크 검토 단계, 본부장 승인 대기**

사용자 요청에 따라 한 사람이 영웅 한 명을 조작하고, 협동은 방 만들기와 참가로 모으는 방향이다. 로컬 2인 기능은 승인 후 제거한다. 사용자는 솔로도 영웅 한 명만 출전하며, 아스트라가 검토 후 본부장 승인을 맡는다고 명시했다. 현재는 이 구체적인 계획에 대한 아스트라 승인을 기다린다.

## 승인할 게임 규칙

| 항목 | 기본안 |
|---|---|
| 홀로 출정 | 영웅 1명과 비기 2개를 선택한다. 두 영웅 선택·교대 조작을 없앤다. |
| 협동 출정 | 방 만들기 또는 방 코드 참가 → 각자 영웅 1명 선택 → 참가자 준비 → 방장 출전. 두 사람이 서로 다른 영웅을 선택하는 기존 규칙을 유지한다. |
| 모바일 조작 | 왼쪽 아래 가상 패드로 내 영웅 이동, 빈 터 터치로 건설, 오른쪽 기술 버튼 후 지점 터치로 시전한다. 이동·건설 전환 버튼은 없앤다. |
| PC 조작 | 내 영웅 한 명을 마우스로 조작한다. 기존 클릭 건설·우클릭 이동·기술 단축키를 유지한다. |
| 로컬 2인 | 준비 화면·전용 방향키/ASDF/E 조작·2P 전용 HUD·세션 진입을 제거한다. 온라인의 두 플레이어·독립 군자금은 유지한다. |
| 합격기 | 온라인 협동 전용으로 유지한다. 솔로의 합격기·두 영웅 집결 버튼과 발동 안내는 숨긴다. 새로운 솔로 필살기는 이번 기본안에 포함하지 않는다. |
| 상대의 일시적 끊김 | 기존 최대30초 재접속 유예와 전투 정지·상태 동기화를 유지한다. |
| 상대의 영구 이탈 | 두 영웅 지휘 인계를 없앤다. 기본안은 협동 전투 종료 후 재입장 안내이며, 승리 보상을 지급하거나 패배로 집계하지 않는다. AI 동료·도중 참가·호스트 교체는 별도 확장으로 둔다. |
| 저장 기록 | 재화·해금·강화·의상·전장 성적은 보존한다. 옛 솔로 편성의 첫 유효 영웅을 새 편성에 사용하고, 과거 협동 통계는 유지한다. |

합격기·협동 임무는 온라인 전용임을 명시한다. 해당 임무가 포함된 전체완료 보너스는 온라인 플레이가 필요할 수 있다는 정책을 승인받으며, 이번 범위에서 임무 보상을 재설계하거나 기존 진행도를 초기화하지 않는다. 솔로 한 영웅 전환에 필요한 난이도 보정은 검증 결과로 정하며, 보류 중인 후반 난이도 전체 조정을 자동으로 재개하지 않는다.

현재 배포 기준 소스로 기본 영웅8명 각각에 대해 **1영웅 상태 생성 → 기술·궁극기 → 1초 진행 → 스냅샷 왕복**을 확인했다. 모두 정상 처리됐고 합격기는 모두 사용할 수 없었다. 이는 한 영웅 캠페인의 난이도나 완주 검증이 아니다. [실행 기록](MOBILE_ONLINE_PLANNING_PROBE.json)

코드 근거는 `screens-play.js`의 솔로 출전/로비, `main.js`의 이탈 처리, `session.js`의 복구, `sim.js`의 이탈·소유권, `abilities.js`의 합격기, `profile.js`의 편성·기록, `data/quests.js`의 합격기 임무다. [기술 검토와 미해결 결정](MOBILE_ONLINE_RISK_REVIEW.json)

## 승인 후 구현 순서

1. **출전 규칙과 저장 호환**: 솔로·온라인의 영웅 수를 한 곳에서 검증하고 이전 편성을 읽는다. 잘못된 방 편성은 전투 시작 전에 거부한다.
2. **방 중심 진입과 이탈 정책**: 로컬 준비/조작 경로를 제거하고 방 생성·참가·준비·출전을 앞에 둔다. 영구 이탈 시 인계를 없애고 재접속과 보상 처리를 정리한다.
3. **모바일 패드와 한 영웅 HUD**: 보류한 초안을 새 규칙에 맞춰 가져온다. 호스트 기준 방향 이동·정지, 근접 교전 중 조작, 두 엄지 조작과 세로/가로 배치를 완성한다.
4. **게임 규칙과 회귀 검사**: 합격기·임무·튜토리얼을 새 모드에 맞춘다. 기존 전투 규칙 보존 검사와 새 1영웅/온라인 편성 검사를 분리한다.
5. **플레이 검수와 배포**: 솔로 성장 경로·공개 온라인2인·실제 휴대폰 조작/복구를 검수하고, 승인된 범위의 검증이 끝난 빌드를 같은 Railway 서버에 반영한다.

## 배포 전 통과할 기준

- 솔로 플레이어1명/영웅1명, 온라인 플레이어2명/각영웅1명, 로컬 진입과 2P 전용 단축키 없음.
- 영웅8명 모두 출전·기술·궁극기·사망/부활·저장/스냅샷 정상. 온라인은 내 영웅만 조작하고 각자 군자금을 사용함.
- 솔로의 합격기/임무 정책과 보통25전장의 성장 경로를 검증. 어려움/지옥의 기존 미완주·후반 조정 보류는 별도 상태로 유지함.
- 모바일360/414 세로·896 가로에서 패드와 버튼이 겹치지 않고, 주요 버튼44px 이상. PC 마우스도 정상.
- 패드 유지+기술/건설, 데드존·손 떼기·영웅 사망·회전·앱 전환 후 이동 유지 없음.
- 실제 호스트/게스트의 지연 이동·재접속·명시적 퇴장·유예 만료·호스트 종료·최종 보상 중복 방지 확인. 호스트 앱이 백그라운드에 들어가면 명시적인 전투 대기 상태를 전달하고, 복귀 후 동기화한다. 새로고침/탭 종료 복원·호스트 승계는 이번 지원 범위에서 제외한다.
- 기존 프로필의 재화·해금·구매·강화·의상·전장 성적이 유지됨.

기기나 네트워크 검수가 빠지면 그 범위를 완료로 표시하지 않고 배포 승인 때 명시한다.
