# 호국영웅전 · 정식 3D 게임

`node server/server.js` 실행 후 `http://localhost:8080/`에서 출정합니다. 정식 화면은 기존 Session·프로필·전투 명령을 사용하고, Renderer3D가 그 상태를 그립니다. `3d.html`의 지원 유산·별 기록은 정식 게임에 적용되지 않습니다.

연속 곡면의 얼굴·의복, 팔꿈치·손목·무릎, 두께 있는 곡선 처마와 석축을 적용한 [최신 조형 모델의 화면·성능·검증](SCULPTED_MODELS.md)을 함께 확인할 수 있습니다.

이후 전용 돌·목재·길·풀밭 재질과 주변 지형을 추가했습니다. [전용 재질과 배경 검증](PAINTED_ENVIRONMENTS.md)에 65개 자동 검사와 최신 화면·성능을 기록했습니다.

그다음 영웅별 얼굴·체형·장비와 실제 손에 연결되는 활, 권총 조준, 발목 보정 보행을 추가했습니다. [영웅 조형·동작 검증](HERO_MODELS_AND_MOTION.md)에 당시 자동 검사 70개와 화면·성능을 기록했습니다.

이어서 일반 병력 10종·적장 12명의 개별 조형, 양손 무기·말·충차 동작과 실제 전투 신호를 연결했습니다. [적군 조형·동작 검증](ENEMY_MODELS_AND_MOTION.md)에 당시 자동 검사 82개, 단일 HTML·모바일 표시와 128명 성능을 기록했습니다.

현재 빌드는 인간형 33종의 곡면 이목구비·피부·모발·직물·갑주·가죽 재질을 사용합니다. [캐릭터 재질 검증](CHARACTER_SURFACES.md)에 자동 검사 **89개**, 의복 16종·조명 비교와 최종 실제 전투·128명 성능을 기록했습니다.

## 연결된 게임 범위

- 타이틀 → 진영 → 5장 25전장 → 영웅 2명·비기 2개 편성 → 실제 전투 → 승패·보상·다음 전장 해금으로 이어집니다. 영웅·비기·유산 영구 강화, 보급품, 의복, 임무·출석·옥 상점과 기존 저장 형식을 유지합니다.
- 영웅 8명, 왜군 22종, 소환 병사·거북선·전령, 유산 10종을 실제 입체 모델로 표시합니다. 의복 16종은 전용 복제 재질을 사용해 다른 캐릭터의 공용 재질을 바꾸지 않습니다.
- 실제 25개 지도에 사계절 재질·조명·날씨를 배치합니다. 길·강·바다·다리와 주변 한옥·나무·바위·등불·항아리를 지도의 위치에 맞춰 조립합니다.
- 유산은 1단계 → 2단계 → 3단계 → 4단계 A/B 최대 특화로 표시합니다. 네 칸 진행 표시, 강화 횟수, 최대 표식과 모델의 지붕·성벽·무장 변화가 함께 바뀝니다. 엔진 상태는 기존 `level=3`과 `branch`를 사용합니다.
- 영웅 기술·궁극기 16개와 비기 8종을 일러스트로 표시합니다. 범위·소환 위치·낙하 착탄 예고·포구 반동·투사체·합격기를 실제 명령/이벤트에 연결했습니다.
- 로컬 2인과 방 코드 온라인 협동을 같은 3D 전장으로 실행합니다. 게스트는 압축 상태의 유산 중심 좌표·공격 배율·특화·투사체를 복원하며, 상대 영웅 이동·상대 유산 철거 권한은 호스트가 검증합니다. 동료 이탈 시 호스트가 영웅·유산·군자금을 넘겨받습니다.
- 설정에서 입체/평면 모드와 높음/가벼운 품질을 선택합니다. WebGL 초기화 실패 시 새 캔버스로 평면 전장을 실행합니다. 소리 설정은 프로필에 저장되며 현재 검증 프로필은 음악·효과음 모두 0입니다.

## 조작

| 입력 | 정식 게임 |
|---|---|
| 클릭·터치 | 영웅·유산 선택, 빈 터 건설, 기술 표적 지정 |
| 우클릭·길 클릭 / 터치 길게 누르기 | 선택 영웅 이동 |
| Q·W / E·R | 혼자 하기의 1번 / 2번 영웅 기술·궁극기 |
| D·F / Space | 비기 1·2 / 합격기 |
| Z·X·C·V | 보급품 |
| N / G | 다음 파도 / 협동 핑 |
| 드래그 / 휠 / 시점 버튼 | 화면 이동 / 확대·축소 / 회전·복귀 |
| 건설 터 / 영웅 집결 | 건설 위치 표시 / 같은 길의 인접 목적지로 이동 명령 |
| 로컬 2P 방향키·A·S·D·F·E·Q·W·Space | 이동·기술·궁극기·비기·건설/확정·취소·다음 파도·합격기 |

건설 고리는 카메라를 따라 이동합니다. 드래그와 클릭을 구분하며, 두 손가락 조작·취소·화면 종료 시 길게 누르기 타이머를 지웁니다. 유산 단계 배지는 화면 경계 안에서 겹침을 피하고 옮겨진 배지는 지붕에 선으로 연결합니다. 선택 유산의 위치를 우선하며 선택·반응형 크기 변화에 맞춰 클릭 영역을 다시 측정합니다.

주변 유산의 불투명 메시가 카메라에서 영웅의 가슴·머리를 가리면 주인 색 실루엣을 표시합니다. 건물 앞·옆의 영웅에는 원래 재질을 유지합니다. 이는 근처 유산의 두 표본과 깊이를 사용한 보완 표시이며 모든 지형·카메라 각도의 완전한 가림 판정은 아닙니다.

| 검증 | 결과 |
|---|---|
| 기존 자체 점검 | 14개 |
| 3D 재질·지형·모델·관절·발사·조준·합격기·밀집 병력 | 41개 |
| 정식 세션·네트워크·저장·의복·입력·가림·단계·상태 배치 | 15개 |
| 실제 Session 25전장 × 3난이도 × 혼자/로컬 | 150개 모두 종료; 67승, 보통 49/50·어려움 15/50·지옥 3/50 |
| 신규 기록 첫 전장 | 12파, 민심 20/20 승리 → 엽전 664(첫 승리 포상 300 포함)·동래성·해인사·어려움 해금 → 저장 복원 |
| 실제 수입으로 보통 캠페인 성장 | 혼자/로컬 × 두 시드, 새 기록 4개 모두 25전장 완주 · 총 138전, 38회 재도전 |
| 최종 전장 지옥 | 최대 강화·을지+강감찬·군량+비격, 정상 이동/철거/강화 명령으로 혼자 민심 8·로컬 민심 7 승리 |

150전투는 seed 7919, 이순신+세종, 신기전+봉수, 한 가지 balanced 봇 전략과 전장별 예상 영구 강화를 사용합니다. 측정 봇의 경로 객체/숫자 ID 비교 오류를 수정한 뒤 다시 생성한 [전체 보고서](RELEASE_VALIDATION.json)입니다. 유일한 보통 패배는 동래성 혼자 하기 최종 파도입니다. 이 승률은 사람의 승률이나 모든 전략의 결과가 아닙니다. 최종 지옥의 [별도 재현 보고서](FINAL_BATTLE_VALIDATION.json)는 최대 강화 구입·재화 수급을 시뮬레이션하지 않으며 지옥 25전장 전체의 밸런스를 보증하지 않습니다.

이 예상 강화의 수급 문제를 따로 검증해 [실제 수입·구입 성장 보고서](PROGRESSION_VALIDATION.json)를 추가했습니다. 전투·임무·품계·한 번의 출석으로 얻은 재화만 사용하며, 영구 강화를 정상 구입하고 저장을 왕복합니다. 장별 보통 첫 승리 포상은 300/600/900/1,200/1,500냥, 25전장 합계 22,500냥이며 난이도별 한 번만 지급합니다. 기존 승리 기록도 지급 일지를 저장해 한 번만 소급합니다. 최종 전장은 남한산성 저지·탐지·석굴암 대광명 재투자로 통과했으며, 같은 실제 성장 기록·같은 시드의 [18개 전략 비교](PAID_FINAL_STRATEGY_VALIDATION.json)도 보존했습니다. 어려움·지옥의 실제 수입 성장과 사람의 체감 난이도는 이 결과에 포함되지 않습니다.

브라우저에서는 실제 방 생성·코드 참가·영웅 중복 차단·준비·양쪽 전투 진입, 건설/강화/군자금 동기화, 상대 철거 차단, 게스트 기술의 호스트 반영과 동료 이탈 인계를 확인했습니다. 로컬 2P의 E·방향키 선택·E 확정·강화, 카메라 회전, 발밑 건설 후 실루엣도 확인했습니다. 온라인 이탈 시 `Net.close()` 뒤 구독 해제가 실패하던 오류는 실제 Net/Session 회귀 검증과 두 브라우저 복귀로 수정 확인했습니다.

단일 HTML을 연 브라우저에서도 정상 건설·강화·기술·합격기 조작으로 부산진 12파도를 민심 20/20, 별 3개로 승리했습니다. [이전 실제 결과 화면](screenshots/game-campaign-victory.jpg)은 포상 추가 전의 엽전 364·옥 30, 해인사와 다음 동래성 해금 기록입니다. 새 통합 점검의 같은 무손실 결과는 포상 300을 포함해 664냥을 지급합니다.

같은 부산진 로컬 전장을 재시작 두 번 후 GPU 지오메트리 103개·텍스처 16개로 돌아왔습니다. PC 검사에서 전장과 창 크기에 따라 48~60fps를 관측했으며 기기별 성능 보장은 아닙니다. [정식 전투 화면](screenshots/game-full-campaign-3d.jpg)과 [414×896 모바일 화면](screenshots/game-full-mobile-3d.jpg)에서 완성·최대 특화 배지가 겹치지 않고, 화면 가로 넘침 없이 건설·강화가 되는 것을 확인했습니다. [평면 모드](screenshots/game-2d-fallback.jpg)도 정식 전투로 진입했습니다. GPT 아스트라 xhigh 검토를 거쳐 숨김 CSS·다중 터치 타이머·실루엣·네트워크 종료 문제를 수정했습니다.

위 성능·자원 수치는 이전 빌드의 기록입니다. 이후 [전체 개선](POLISH_RELEASE.md), [조형 모델](SCULPTED_MODELS.md), [전용 재질과 주변 지형](PAINTED_ENVIRONMENTS.md), [영웅 조형·동작](HERO_MODELS_AND_MOTION.md)의 버전별 측정을 보존했습니다. 가장 최근 수치는 [적군 조형·동작 검증](ENEMY_MODELS_AND_MOTION.md)을 기준으로 확인하세요.

## 빌드와 재현

```bash
npm install
node tools/build-3d.mjs
node tools/selftest.mjs
node tools/test-3d.mjs
node tools/test-campaign.mjs
node tools/test-enemies.mjs
node tools/verify-release.mjs
node tools/verify-final-battle.mjs
node tools/verify-progression.mjs --seeds=2 --attempts=12
node tools/verify-paid-final.mjs
node tools/build.mjs
```

`dist/hoguk.html`은 엔진과 그림을 포함하는 단일 파일입니다. 생성한 파일을 로컬 서버의 `/dist/hoguk.html?mute=1`에서 열어 전투·보상·진영 복귀와 모바일 건설을 확인했습니다. 자동 브라우저의 보안 정책으로 `file://` 직접 열기는 검사하지 못했습니다. 혼자/로컬 협동은 서버 없이 실행하도록 묶었으며 온라인은 Node 서버의 기본 게임 주소(`/`)에서 실행합니다. 단일 파일 화면의 방 기능은 비활성화합니다. 선택 웹 글꼴이 없으면 시스템 글꼴을 사용합니다. `?mute=1`로 열면 처음 클릭하기 전부터 음악·효과음을 0으로 저장합니다. 자유 미리보기도 정식 프로필의 효과음 음량을 따릅니다. 모델은 코드로 조립한 관절 모델이며, 별도 DCC 제작 고해상도 캐릭터·완전한 모션 캡처·새 장애물 길찾기는 포함하지 않습니다.
