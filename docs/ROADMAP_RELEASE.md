## 배포 파일

`npm run build:web`은 `dist/web/`을 만든다. 그림 163파일은 원본 배포 자산과 바이트가 같고 보존용 `/source/`는 제외한다. 실행 HTML은 1,002바이트, 게임 스크립트는 1,391,131바이트이며 gzip 전송은 398,666바이트다. **첫 화면이 이 용량만으로 완성된다는 뜻은 아니다.** 메뉴·선택 캐릭터·전장에 필요한 그림을 별도로 요청한다. 전체 그림은 90,348,630바이트, manifest가 집계한 배포 파일은 93,756,562바이트다.

`python tools/package-web.py`로 만든 `dist/hoguk-web.zip`은 91,874,287바이트, manifest 포함189파일이다. 원본 코드와 이미지 보존 자료를 모두 받지 않고 배포 파일만 전달할 수 있다. Python 표준 라이브러리만 사용한다. ZIP을 풀어 `hoguk-web` 폴더에서 다음을 실행한다. 서버 런타임은 Node18 이상이며 별도 패키지 설치가 필요 없다.

```powershell
npm start
```

`http://localhost:8080/?mute=1`에서 솔로·로컬2인·온라인을 사용할 수 있다. 온라인은 같은 서버의 기본 HTTP 주소를 쓴다. 같은 네트워크에 노출할 때만 기존 방식대로 HOST를 명시한다. 공개 호스팅이나 포트 개방을 실행한 작업은 아니다.

기존 `npm run build`의 `dist/hoguk.html`도 유지한다. 새 파일은 **121,854,634바이트**다. 전체 그림을 내장해 솔로·로컬2인용으로 쓸 수 있으며 온라인은 서버용 기본 페이지에서 실행한다. 새 세 WebP를 각각 한 번 담고 보존 PNG는 제외했다. `file://` 직접 실행은 이번 브라우저에서 검증하지 않았다.

## 입력과 성능

창이 초점을 잃거나 문서가 숨겨지면 누른2P키와 예약된 터치 긴 누르기를 해제한다. 취소 뒤 pointerup이 잘못된 건설·이동 명령을 발생시키지 않도록 했다. 프레임 계측은 실제 시각을 사용하며 숨김 뒤 복귀 구간은 분리한다. 전경의 긴 프레임을 좋은 값으로 숨기지 않는다. [10개 검사](DEVICE_READINESS_RUNTIME_VALIDATION.json)와 [실제 브라우저 관측](DEVICE_BROWSER_CENSUS.json)을 보존한다. 브라우저 절전으로1FPS가 된 초기 표본과 이후60FPS 표본을 함께 남겼으며 인증 성능 수치로 일반화하지 않는다. 캔버스 저장량은 전체 RAM 수치와 구분한다.

## 재접속

비정상 이탈은 서버 감지 뒤 슬롯을30초간 예약한다. 탭 메모리에만 둔 재개 토큰으로 복구하며, 정상 나가기는 즉시 반영한다. 재접속 동안 호스트 전투·양측 명령을 멈춘다. 전체 건물 상태를 포함한 스냅샷과 원화 준비 뒤 최신 동기화 ID의 ACK를 받아 재개한다. 끊김 중 명령은 다시 실행하지 않는다. 오래된 소켓의 늦은 종료·오래된 ACK는 현재 연결을 해제하지 않는다.

완료 상태와 통계는 하나의 finish로 서버에 보관한다. 복구 중에는 기다리며 ACK를 확인한 뒤 결과 화면으로 진행한다. 영구 단절 또는 연결된 상태의 대기 한도에서는 ACK 없이 진행할 수 있다. 게스트는 호스트가 정리한 뒤에도 제한 시간 안에 결과를 복구할 수 있다. 캐시는 기본60초다. 서버 재시작·탭 재로드·호스트 영구 이탈의 호스트 이전은 구현 범위가 아니다. 정상 이탈 시 기존 인계 규칙을 따른다.

실제 루프백 WebSocket에서 게스트·호스트·동시 끊김, 시작 메시지 유실, 결과 전달, 만료, heartbeat, backlog, 잘못된 프레임을 포함한 **22개**를 통과했다. Astra 하이는 겹치는 동기화 요청의 오래된 ACK 거절을 확인했다. 검사 자체가 다음 프레임을 호출하지 않던 문제는 실제 RAF 순서대로 수정하고 결정적인 재현 사례를 추가했다. [네트워크 검사](NETWORK_RECOVERY_VALIDATION.json).

## 검증과 기록

전체 **395개 / 29검사군**을 통과했다. 기준 솔로·협동 완주2판의 전투·수입·사건·기존 snapshot SHA는 유지했다. 새 원화는 무손실 픽셀·투명 경계·부분 실패·종료 자원 해제를 검사했다. 실제 웹 패키지의 로컬2인에서 양측 건설과 독립 군자금을 확인했고, 건설 메뉴는 여러 크기의 실제 DOM 영역으로 검수했다. 모든 작업 브라우저는 무음이며 사용자 Chrome과 기존8092서버를 재시작하거나 새로고침하지 않았다.
